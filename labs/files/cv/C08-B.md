# السيرة الذاتية · C08-B

الاسم: نبيل شوقي لبيب
سنة الميلاد: 1998
مكان الإقامة: الرياض

## المؤهل

بكالوريوس في نظم المعلومات

## الخبرة

سنتان في قسم التحليل لدى شركة مقاولات:

- تنظيف بيانات المبيعات الشهرية وتوحيدها
- كتابة استعلامات SQL على مستودع البيانات
- إعداد تقارير أسبوعية في جداول البيانات
- متابعة أرصدة المخزون وإدخالها

## المهارات

جداول البيانات، SQL

## اللغات

العربية، والإنجليزية للقراءة التقنية
